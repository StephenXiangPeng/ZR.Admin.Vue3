# DCBL 库存管理操作手册

## 1. 手册说明

本文档用于指导用户使用 DCBL 模块完成配件/产品资料维护、入库、出库、库存查看和库存调整等日常操作。

当前模块包含以下功能页面：

- 配件/产品管理：维护基础资料、成品配件组成。
- 入库管理：登记、查看、编辑、删除入库记录。
- 出库管理：登记、查看、编辑、删除出库记录。
- 库存台账：查看当前库存和库存流水。
- 库存调整：登记库存增加或减少，并查看、删除调整记录。

库存变化主要由入库、出库和库存调整产生。库存台账页面仅用于查看，不直接修改库存。

## 2. 基础概念

### 2.1 配件/产品

系统将库存对象统一称为配件/产品，常见类型包括：

- 配件：可作为成品组成部分的库存对象。
- 产品/成品：可配置配件组成的库存对象。

类型和单位来自系统字典配置：

- 类型字典：`dc_material_classification`
- 单位字典：`dc_material_unit`

### 2.2 库存数量

库存数量表示当前可用库存。入库会增加库存，出库会减少库存，库存调整可按选择的调整类型增加或减少库存。

### 2.3 成品配件组成

当配件/产品类型为产品或成品时，可维护其配件组成。每条组成关系包含：

- 配件
- 用量

同一个成品下不能重复选择相同配件，用量必须大于 0。

## 3. 配件/产品管理

### 3.1 查询配件/产品

进入配件/产品管理页面后，可通过以下条件查询：

- 名称：输入配件或产品名称，支持回车搜索。
- 类型：选择配件、产品/成品等类型。

点击“搜索”执行查询，点击“重置”清空查询条件并重新加载列表。

列表展示字段包括：

- 序号
- 名称
- 类型
- 单位
- 规格
- 当前库存
- 备注
- 配件组成
- 操作

### 3.2 新增配件/产品

操作步骤：

1. 点击“新增”。
2. 填写名称、类型、单位、规格和备注。
3. 如果类型为产品/成品，可在“配件组成”中点击“添加配件”。
4. 选择配件并填写用量。
5. 点击“确定”保存。

必填项：

- 名称
- 类型
- 单位

填写规则：

- 名称最多 50 个字符。
- 规格最多 100 个字符。
- 备注最多 200 个字符。
- 配件用量必须大于 0。
- 同一成品不能重复选择同一个配件。

### 3.3 编辑配件/产品

操作步骤：

1. 在列表中点击目标记录右侧的“编辑”。
2. 修改基础信息或配件组成。
3. 点击“确定”保存。

编辑产品/成品时，系统会加载该产品已有的配件组成，用户可继续新增或删除配件行。

### 3.4 删除配件/产品

操作步骤：

1. 在列表中点击目标记录右侧的“删除”。
2. 在确认框中确认删除。

删除成功后，列表会自动刷新。删除前应确认该配件/产品不再需要使用，避免影响后续入库、出库或库存查询。

### 3.5 查看配件组成

如果产品/成品存在配件组成，列表中会显示“查看配件”。

点击后可查看：

- 配件名称
- 规格
- 单位
- 用量

## 4. 入库管理

### 4.1 查询入库记录

可通过“配件/产品”筛选入库记录。

列表展示字段包括：

- 序号
- 名称
- 类型
- 单位
- 入库数量
- 入库时间
- 备注
- 操作

点击“搜索”执行查询，点击“重置”清空查询条件。

### 4.2 新增入库

操作步骤：

1. 点击“新增入库”。
2. 选择配件/产品。
3. 填写入库数量。
4. 选择入库时间，默认会带出当前时间。
5. 填写备注。
6. 点击“确定”保存。

必填项：

- 配件/产品
- 数量
- 入库时间

填写规则：

- 数量必须为正数。
- 当前页面数量输入为整数。
- 备注最多 200 个字符。

保存成功后，系统提示“新增入库成功”，并刷新配件/产品下拉和列表。入库记录会增加对应配件/产品库存。

### 4.3 查看入库详情

在列表中点击“查看”，可查看该入库记录的完整信息：

- 名称
- 类型
- 单位
- 入库数量
- 入库时间
- 备注

### 4.4 编辑入库记录

操作步骤：

1. 在列表中点击“编辑”。
2. 修改配件/产品、数量、入库时间或备注。
3. 点击“确定”保存。

保存成功后，系统提示“编辑入库成功”，并刷新列表。编辑入库记录可能会重新计算库存。

### 4.5 删除入库记录

操作步骤：

1. 在列表中点击“删除”。
2. 在确认框中确认删除。

删除成功后，系统提示“删除入库成功”，并刷新列表。删除入库记录通常会冲减对应库存，操作前应确认业务记录无误。

## 5. 出库管理

### 5.1 查询出库记录

可通过“配件/产品”筛选出库记录。

列表展示字段包括：

- 序号
- 名称
- 类型
- 单位
- 出库数量
- 用途
- 出库时间
- 备注
- 操作

点击“搜索”执行查询，点击“重置”清空查询条件。

### 5.2 新增出库

操作步骤：

1. 点击“新增出库”。
2. 选择配件/产品。
3. 填写出库数量。
4. 选择或输入用途。
5. 选择出库时间，默认会带出当前时间。
6. 填写备注。
7. 点击“确定”保存。

必填项：

- 配件/产品
- 数量
- 出库时间

填写规则：

- 数量必须为正数。
- 当前页面数量输入为整数。
- 用途可从字典中选择，也可手动输入。
- 备注最多 200 个字符。

用途字典为：`dc_usagetype`。

保存成功后，系统提示“新增出库成功”，并刷新配件/产品下拉和列表。出库记录会减少对应配件/产品库存。

### 5.3 查看出库详情

在列表中点击“查看”，可查看该出库记录的完整信息：

- 名称
- 类型
- 单位
- 出库数量
- 用途
- 出库时间
- 备注

### 5.4 编辑出库记录

操作步骤：

1. 在列表中点击“编辑”。
2. 修改配件/产品、数量、用途、出库时间或备注。
3. 点击“确定”保存。

保存成功后，系统提示“编辑出库成功”，并刷新列表。编辑出库记录可能会重新计算库存。

### 5.5 删除出库记录

操作步骤：

1. 在列表中点击“删除”。
2. 在确认框中确认删除。

删除成功后，系统提示“删除出库成功”，并刷新列表。删除出库记录通常会回补对应库存，操作前应确认业务记录无误。

## 6. 库存台账

### 6.1 查询当前库存

库存台账页面用于查看当前库存，不提供新增、编辑或删除库存的入口。

可通过以下条件查询：

- 名称：输入配件或产品名称，支持回车搜索。
- 类型：选择配件、产品/成品等类型。
- 库存状态：
  - 全部
  - 有库存（>0）
  - 无库存（=0）

列表展示字段包括：

- 序号
- 名称
- 类型
- 规格
- 单位
- 当前库存
- 最后更新时间
- 操作

无库存记录会以弱化样式展示，便于区分。

### 6.2 查看库存流水

操作步骤：

1. 在库存列表中点击“查看台账”。
2. 在弹窗中查看该配件/产品的库存变动明细。
3. 可通过分页查看更多流水记录。

库存流水展示字段包括：

- 时间
- 变动类型
- 变动数量
- 变动前库存
- 变动后库存
- 来源类型
- 备注

常见变动类型包括：

- 入库
- 出库
- 入库修改
- 删除入库
- 出库修改
- 删除出库

正数变动数量表示库存增加，负数变动数量表示库存减少。

## 7. 库存调整

### 7.1 查询库存调整记录

可通过以下条件查询：

- 配件/产品：选择具体库存对象。
- 调整类型：增加或减少。

列表展示字段包括：

- 序号
- 名称
- 类型
- 单位
- 调整类型
- 调整数量
- 调整原因
- 调整时间
- 备注
- 操作

### 7.2 新增库存调整

操作步骤：

1. 点击“新增调整”。
2. 选择配件/产品。
3. 选择调整类型：增加或减少。
4. 填写调整数量。
5. 选择调整原因。
6. 选择调整时间，默认会带出当前时间。
7. 填写备注。
8. 点击“确定”保存。

必填项：

- 配件/产品
- 调整类型
- 调整数量
- 调整原因
- 调整时间

填写规则：

- 调整数量必须为正数。
- 当前页面数量输入为整数。
- 调整原因来自字典 `dc_inventory_adjustment`。
- 备注最多 200 个字符。

保存成功后，系统提示“新增库存调整成功”，并刷新配件/产品下拉和调整列表。

### 7.3 查看库存调整详情

在列表中点击“查看”，可查看该调整记录的完整信息：

- 名称
- 类型
- 单位
- 调整类型
- 调整数量
- 调整原因
- 调整时间
- 备注

### 7.4 删除库存调整记录

操作步骤：

1. 在列表中点击“删除”。
2. 在确认框中确认删除。

删除成功后，系统提示“删除库存调整成功”，并刷新列表。删除调整记录可能影响库存结果，操作前应核对调整原因和时间。

## 8. 推荐业务流程

### 8.1 初始化资料

1. 在配件/产品管理中维护配件资料。
2. 在配件/产品管理中维护产品/成品资料。
3. 如产品/成品由配件组成，维护对应配件组成和用量。
4. 在库存台账中确认基础资料已出现。

### 8.2 日常入库

1. 在入库管理中新增入库记录。
2. 保存后到库存台账查询当前库存。
3. 如需追溯库存变化，点击“查看台账”查看库存流水。

### 8.3 日常出库

1. 在出库管理中新增出库记录。
2. 填写用途，便于后续追踪出库原因。
3. 保存后到库存台账确认库存已减少。

### 8.4 盘点差异处理

1. 先在库存台账中确认当前库存。
2. 根据实际盘点差异，在库存调整中新增调整记录。
3. 选择正确的调整类型和调整原因。
4. 保存后回到库存台账确认调整结果。

## 9. 注意事项

- 新增、编辑或删除入库/出库记录前，应确认数量、时间和对象准确无误。
- 库存调整适用于盘盈、盘亏或其他非正常出入库场景，不建议替代正常入库和出库流程。
- 库存台账只用于查询，不能直接修改库存。
- 删除业务记录可能影响库存，应谨慎操作。
- 配件/产品删除前，应确认没有仍需追溯的业务记录。
- 如果下拉框中缺少类型、单位、用途或调整原因，请联系管理员检查对应字典配置。
